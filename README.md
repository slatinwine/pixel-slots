# PIXEL SLOTS · 像素老虎机

单文件 HTML5 像素风老虎机游戏，零依赖，Canvas 逐像素手绘符号 + Web Audio 合成芯片音效。

**在线试玩：https://slatinwine.github.io/pixel-slots/**

## 操作

| 按键/操作 | 功能 |
|------|------|
| 空格 / SPIN 按钮 / 拉杆 | 开始旋转 |
| BET- / BET+ | 调整注额（1/5/10/25/50） |
| MAX | 满注（解锁两条斜线奖路） |
| SND:ON | 音效开关 |

## 赔付表（× 注额，每条奖线）

| 组合 | 倍数 |
|------|------|
| 7 7 7 | **×200 头奖** |
| ◇ ◇ ◇ | ×60 |
| 铃铛 ×3 | ×30 |
| 星星 ×3 | ×15 |
| 樱桃 ×3 | ×10 |
| BAR ×3 | ×8 |
| 柠檬 ×3 | ×3 |
| 任意两颗樱桃 | ×2 |

- 3 条横线常开，MAX BET(50) 额外解锁 2 条斜线
- 777 头奖：机身震动 + 金币雨 + 彩带 + 跑马灯狂闪
- 分数与注额自动存档（localStorage），破产可领 +200 补助
- CRT 扫描线滤镜、拉杆动画、芯片音效实时合成（Web Audio）
